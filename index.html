System Architecture & Data Flow

End-to-End Hardware Integration & Embedded Pipeline

Data Pipeline Topology

The system operates on an asynchronous FreeRTOS architecture. Core 0 is dedicated to real-time deterministic sensor polling (ultrasonic sonar echo capture via input capture interrupts and I2C temperature telemetry). Core 1 manages the Edge AI neural network inference pipeline, GPS NMEA parsing, and SIM800L AT command state machine for cellular dispatch.

INPUT Sonar & Vision Echo timings & raw 120° frames
DMA ESP32 Buffer Zero-copy DMA memory transfer
INFERENCE Neural Engine TFLite quantized object detection
HAPTIC Guidance Actuator Directional vibration frequency
UPLINK Cloud & Caregiver GSM alert & live GPS telemetry
